# [MAN-01] PVD AlCu 증착 불량 대응 총괄 절차

> 문서번호: MAN-01 | 개정: Rev.2 | 적용 공정: PVD AlCu 금속층 증착
> ※ 이 문서는 교육·실습용으로 작성한 **가상 매뉴얼**이며 실제 설비·기업의 절차가 아닙니다.

## 1. 적용 범위
AlCu 증착 후 계측에서 두께(thickness), 면저항(sheet resistance), 비저항(resistivity) 중 하나 이상이 Bad로 판정되었거나,
불량 예측 모델이 '불량 의심'으로 판정한 웨이퍼에 적용한다.
예측 모델의 판정은 계측을 대신하지 않으며, 반드시 계측 결과로 최종 확인한다.

## 2. 불량 의심 웨이퍼 처리 흐름
1. 해당 웨이퍼와 같은 lot의 남은 웨이퍼를 즉시 Hold 한다. 진행 중인 run은 현재 웨이퍼까지만 완료한다.
2. 불량 의심 웨이퍼를 17포인트 두께·면저항 재측정한다. 재측정 결과가 Good이면 Hold를 해제하고 '오판정'으로 기록한다.
3. 재측정에서도 Bad이면 불량 유형을 분류한다.
   - 두께·면저항이 웨이퍼 전체에서 함께 벗어남 → 증착률 문제: MAN-04(타깃 파워) 점검
   - 중심(point 1)과 가장자리(point 17) 차이가 큼 → 균일도 문제: MAN-02, MAN-03 점검
   - 비저항만 벗어남 → 막질 문제: MAN-05(온도), MAN-03(진공·가스) 점검
4. 센서 통계 중 기준 대비 크게 벗어난 항목을 확인하고 해당 설비 매뉴얼을 따른다.
   - PRESS_*, GAS*, FLOW_* → MAN-03
   - POWER_TARGET_*, VOLTS_TARGET_*, AMPS_TARGET_*, OHM_TARGET_* → MAN-04
   - TEMP_PLATEN_*, DCBIAS_PLATEN_* → MAN-05
   - LIFE_*, UTILISATION_TARGET_*, WAFERCOUNT_* → MAN-06
5. 원인 조치 후 시험 웨이퍼(monitor wafer) 1매를 증착·계측해 Good이면 설비를 재가동한다.

## 3. 판정 기준
- 예측 점수가 모델 임계값 이상이면 '불량 의심'으로 본다.
- 같은 설비에서 연속 3매 이상 불량 의심이 나오면 설비 이상으로 간주하고 설비를 정지한다.
- 같은 lot에서 Bad 비율이 20%를 넘으면 lot 전체를 재측정한다.

## 4. 보고 및 에스컬레이션
- 모든 불량 의심 건은 설비 로그에 웨이퍼 ID, 예측 점수, 재측정 결과, 조치 내용을 기록한다.
- 설비 정지가 필요한 경우 공정 엔지니어와 설비 엔지니어에게 즉시 알린다.
- 원인을 4시간 안에 찾지 못하면 공정 기술팀장에게 보고한다.
